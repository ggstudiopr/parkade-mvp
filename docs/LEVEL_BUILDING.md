A level only has a few required components:
	- Player (to navigate the world)
	- Collisions (the world to navigate)

Additional components can be used to create the desired gameplay mechanics:
	- EventManager: the moments that denote a change in the world
	- AnimationPlayers: Changes to the world the Events can use
	- Vehicle: Alternate way to navigate the world
	
	- EnemyManager - Adds enemies to interact with Player
